# Cheat sheet — Partnership type & first ask

*One page. Use it to choose what to propose. A person decides; the sheet only guides.*
Part of the [lean specification](../lean-spec.md).

## 1. Which partnership types fit? (tick all that apply)

| If this is true… | …this type fits | Typical first ask |
|---|---|---|
| **F2 Content fit = 2** (a named person or concrete idea for a current theme) | **Speaker** | One talk / panel seat. No money involved |
| **F3 = 2 because they hire CBS-type profiles** | **Recruitment** | Case workshop or recruitment event |
| **F4 = 2** (sponsors student organisations, or has paid us) **and** Access ≥ 3 (warm) | **Event sponsor** | One sponsored event, or a series |
| Event sponsor fits **and** they have been satisfied before **and** F5 = 2 | **Recurring sponsor** | The same event series every semester |
| **Two or more** of the above **and** F5 = 2 **and** a satisfied past partnership | **Annual partner** | One agreement covering several deliverables for a year |
| They have data, research or real expertise on a current theme | **Knowledge partner** | Data or an expert for one debate. Check the independence policy first |
| They have their own channels (podcast, media, strong social) | **Content partner** | A co-produced piece (episode, interview) |
| They can open doors to speakers or other partners (VC, association, network) | **Networking partner** | Introductions to 2–3 speakers |
| They have something we need right now (venue, catering, AV, printing) | **In-kind** | That specific item, for a specific date |
| None of the above | — | Don't approach now |

## 2. Choosing the first ask

1. **Start with the easiest step that serves both sides.** In order of effort:
   speaker → networking → in-kind → recruitment → content/knowledge → sponsorship → annual.
2. **No cash ask in the first contact unless Access ≥ 3** (warm or better). A cold money request
   usually closes the door for a year.
3. **Long-term partnerships grow:** first event → good partner report → renewal → bigger package.
4. **Never offer what the independence policy doesn't allow** (they don't choose our other speakers or our conclusions).

## 3. Which package? (based on Commercial Evidence, never on a budget guess)

| Commercial Evidence | Propose |
|---|---|
| `previous_cbs_talks_spend` and satisfied | The **same package**, or **one level up** if the event delivered well |
| `previous_cbs_talks_spend`, satisfaction neutral/unknown | The same package; ask what would make it more valuable |
| `sponsors_student_orgs`, and the level is visible (e.g. "main partner") | The package that matches that level |
| `sponsors_student_orgs`, level unknown | The **standard** package; ask about their usual approach |
| `sponsors_university_activities` or `sponsors_similar_events` | The **entry** package, or a non-cash first step |
| `none_found` | A **non-cash first step** (speaker, workshop); money only after a successful event |

Prices come from the CBS Talks package list. Never quote a company "their budget", and never mention what other companies pay.

## 4. Write it down

In the opportunity record, write **one sentence**: *"Proposing \<type\> because \<the Fit reason / evidence\>."*
If you choose a type the sheet doesn't suggest, say why. That's fine; the sheet is a guide, not a rule.
