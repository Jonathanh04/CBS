# Archive — superseded design documents

**Do not build from these documents.** They are replaced by the
[lean specification](../lean-spec.md). The reasons are in the [audit](../audit.md).

They are kept as background reasoning. Some ideas may become useful later, once
CBS Talks has real data, e.g. calibrated stage probabilities (CRM), financial
calibration (financial model) or type-specific likelihood (outreach likelihood).

| Document | What it was | Status |

| `partnership-scoring-design.md` | First architecture, data model, critique and MVP | Superseded; GDPR notes carried into the cheat sheets |
| `scoring-framework.md` | Nine-dimension Priority Score and sub-scores A–G | Replaced by Fit (0–10) + Access (0–4) |
| `explainability-layer.md` | Recommendation card with V/I/? tagging | Replaced by the three evidence labels and the manual briefing |
| `recommendation-engine.md` | Rule engine for partnership types | Replaced by the partnership type cheat sheet |

| `outreach-likelihood-and-matrix.md` | Ten-factor outreach score and 2×2 | Replaced by the Access ladder and the lean 2×2 |
| `contact-discovery-layer.md` | Contact plan rule engine | Replaced by the who-to-contact cheat sheet |
| `outreach-briefing.md` | Generated briefings and objection library | Replaced by the manual briefing template and the conversations cheat sheet |
| `partnership-crm.md` | CRM with probabilities and expected value | Simplified in the lean spec (§4, §9) |
| `prototype/pipeline-dashboard.html` | Dashboard prototype for the old CRM | Out of date; shows probabilities and expected values the lean spec drops |
